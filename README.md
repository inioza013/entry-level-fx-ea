# Entry Level FX EA — Website Phase 1

Luxury dark / champagne gold static website for GitHub Pages.

## Files
- `index.html` — landing page, rental EA catalog, custom EA brief, FAQ, contact and risk disclaimer
- `styles.css` — responsive styling
- `script.js` — WhatsApp CTA, custom EA brief form, mobile menu
- `assets/favicon.svg` — initial favicon

## Before publishing
1. Confirm/change the WhatsApp contact number in `script.js` (`WHATSAPP_NUMBER`).
2. Register/confirm ownership of `entrylevelfxea.com`.
3. Create GitHub repository `entry-level-fx-ea` under the desired account.
4. Upload all files to the repository root on `main`.
5. Enable GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
6. Configure custom domain `entrylevelfxea.com` in GitHub Pages and DNS records at domain registrar.
7. Verify HTTPS after DNS propagation.

## Important
This is Phase 1: a static catalog and lead-generation site. No checkout, payment gateway, license server, database, customer login, or admin dashboard is connected yet. Rental EA V2.1 is marked as development/testing and not publicly rentable until verified.
