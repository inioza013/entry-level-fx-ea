Ketentuan lisensi EA

Lisensi EA mengikat nomor akun MT5, nama server broker, dan masa sewa—bukan IP VPS. Jika berpindah VPS tetapi akun dan server broker tetap sama, lisensi pada prinsipnya tetap dapat digunakan. Perubahan akun atau server memerlukan verifikasi dan penerbitan lisensi baru. File source code .mq5 tidak termasuk dalam paket rental.

VPS SERVICE FAQ

Good to know
before ordering.

Apakah saya bisa menggunakan EA jika hanya punya HP? +

Bisa dengan bantuan Windows VPS. EA berjalan di MT5 desktop pada VPS, sedangkan HP digunakan untuk memantau melalui MT5 Android dan mengakses desktop melalui Remote Desktop.

Apakah saya wajib membeli VPS dari Entry Level FX EA? +

Tidak. Anda dapat menggunakan VPS Windows milik sendiri melalui pilihan BYOVPS.

Apakah lisensi EA berubah jika saya pindah VPS? +

Lisensi mengikat akun MT5 dan nama server broker, bukan IP VPS. Perpindahan VPS tidak dengan sendirinya mengubah lisensi selama akun dan server broker tetap sama.

Apakah biaya VPS sudah termasuk rental EA? +

Tidak. Rental EA dan VPS merupakan komponen terpisah. Rincian biaya disampaikan sebelum pelanggan menyetujui pemesanan.

Apakah Entry Level FX EA menjamin VPS selalu online atau profit? +

Tidak. Ketersediaan server bergantung pada provider, koneksi, broker, dan faktor teknis lainnya. VPS dan EA tidak menjamin profit atau menghilangkan risiko trading.

Apakah pelanggan memberikan password trading kepada tim? +

Pelanggan sebaiknya memasukkan sendiri password trading pada sesi Remote Desktop. Hindari mengirim atau membagikan password trading melalui chat. Akses VPS yang diberikan untuk instalasi sebaiknya bersifat sementara dan diamankan kembali setelah pekerjaan selesai.
